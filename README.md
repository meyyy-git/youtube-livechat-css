# youtube-livechat-css-skill

Installs the `$youtube-livechat-css` Codex skill for designing one-file YouTube Live Chat themes for OBS browser sources.

```bash
npx youtube-livechat-css-skill
```

Run again with `--force` to update an existing installation:

```bash
npx youtube-livechat-css-skill --force
```

The installer copies the bundled skill to `$CODEX_HOME/skills/youtube-livechat-css`, or `~/.codex/skills/youtube-livechat-css` when `CODEX_HOME` is unset.
